# 와인 경험 목표 (wine.byb.kr 오프닝) — 모든 구현의 판단 기준

> 이 문서는 프로젝트의 최상위 목표다. **앞으로 모든 구현·기술 선택·튜닝은 이
> 문서의 관점에서 검토한다.** 결정이 애매하면 "이게 아래 목표에 기여하는가"로 판단.

## 최상위 목표
**처음 접속한 사람이 '신기하다'고 느끼게 한다.** 그러려면 아래 네 축이 최대한
실사(photoreal)에 가까워야 한다:
1. **처음 와인을 따르는 효과(pour)** — '진짜' 같아야 한다 (사용자 명시 강조)
2. **스월링(swirling)**
3. **와인 빛깔(color)**
4. **와인잔(glass)**

## 실제 와인 관찰 (도메인 근거 — 구현 판단의 사실 기준)
사용자가 실제 와인잔으로 확인한 것:
- 보통 양으로 채워 스월링하면, 물방울이 따로 놀지 않고 **수평면이 크게 흐트러지지
  않은 채 회전**한다 → **응집된 표면**의 움직임.
- 입자처럼 부서지고 섞이는 움직임은 **아주 적게 담고 빠르게 돌려야만** 나온다.
- 아무리 따라도 **크라운(왕관) 스플래시가 없다** — 와인 점성이 우유만큼 높지 않아서.

## 채택한 구현 방향 (2026-08-23 전환)
입자 유체(PBF/MPM) → **표면·부피 기반 + 절차적 스트림**.
- 근거 1: 주요 장면(스월·정지·색)은 "응집 표면"이지 "입자 무리"가 아니다(위 관찰).
  입자 시뮬은 그 반대(부서짐/튐)에 강한 도구라 애초에 목적과 안 맞았다.
- 근거 2: 입자법은 **입자 사이 빈틈·거친 표면·해상도 천장·정지 지터**를 싸게는
  못 벗어난다(축적된 증거 — docs/fluid-simulation-status.md).
- 구성:
  - **잔/병 속 와인** = 액체 표면(높이장/클립면) + 부피, **Beer–Lambert 색 + 굴절**.
  - **스월** = 표면을 기울이고 회전 모드를 얹음(응집 회전, 수면 유지).
  - **붓기** = 스포우트→잔 **절차적 스트림**(낙하하며 가늘어짐), 닿으면 수위 상승 +
    잔물결. **크라운 없음**(와인 점성).
  - 필요 시(소량·고속 스월의 부서짐)에만 **소수 입자 스플래시 하이브리드**.

## 보존 자산 (어떤 길이든 계승)
- 와인잔 구조(프로파일), 와인병 구조(보르도 750ml 규격, 내부 부피 검증 ~773ml)
- 좌표/스케일 매핑, **직접 굴절 유리**(sceneRT 굴절), Beer–Lambert 색 아이디어
- 붓기 연출(병을 세운 채 기울여 따름, 피벗 회전)

## 검토 렌즈 (모든 구현·결정을 이걸로 평가)
1. **실사에 가까운가?** — 색(깊이 흡수)·굴절·표면 매끈함·움직임의 자연스러움
2. **'신기하다'를 주는가?** — 첫인상 임팩트
3. **실제 와인 거동과 맞는가?** — 응집 표면 회전, 크라운 없음, 적정 점성
4. **네 축(붓기·스월·색·잔)을 다 살리는가?**
