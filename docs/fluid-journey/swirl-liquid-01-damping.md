# 스월 액체감 개선 ① — 2차 난류 감쇠

여자친구 피드백: 스월이 액체 같지 않고 젤리 같다. 원인 분석 중 첫 번째 손질.

## 문제
슬로싱이 **단일 고유진동수 + 거의 무손실(ζ=0.055) 감쇠 스프링**이라, 잔을 놓으면
수면 전체가 한 몸으로 오래 규칙적으로 넘실댄다. 이건 탄성체(젤리)의 물리 그 자체다.

## 변경 (`FluidLab.tsx` render 루프)
감쇠에 속도(진폭) 의존 2차 항을 더했다:

```
damp = 2ζω + QUAD·|v|   (QUAD = 3.0)
```

크게 출렁일수록 손실이 커져(난류 드래그), 놓으면 한두 번 크게 흐트러지고 빠르게
잦아든다. 작은 진폭에선 선형 항만 남아 부드럽게 멈춘다.

## 수치 검증 (`slosh-sim`, 초기 기울기 0.5, 구동 0으로 놓은 상태)
| QUAD | 0.05까지 정착 | 초기 0.5s 진폭 감소 |
|---|---|---|
| 0 (현행) | 5.45s | 0.49 → 0.21 |
| 1.5 | 1.97s | 0.49 → 0.13 |
| **3.0 (채택)** | **1.22s** | **0.49 → 0.10** |
| 4.5 | 0.87s (다소 급함) | 0.49 → 0.08 |

현행은 5.5초간 규칙적으로 넘실(젤리). 3.0은 크게 한 번 흐트러지고 ~1.2초에 정착.
스월을 계속 도는 동안은 구동(COUPLE·잔속도)이 유지되므로 출렁임은 그대로 산다.

## 성능
프레임당 `hypot` 1회 + 스칼라 몇 개. 정점 수·`computeVertexNormals` 비용 불변.
