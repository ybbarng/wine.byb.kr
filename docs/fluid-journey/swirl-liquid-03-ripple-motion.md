# 스월 액체감 개선 ③ — 미세물결에 이동·명멸 부여

## 문제
표면 미세물결(`normalNode`의 fbm 노이즈)이 **위치 고정**이었다(3번째 좌표 `float(0)`).
그래서 물결이 "정지한 얼룩"처럼 붙어 있어, 매끈한 탄성막 위에 무늬만 입힌 느낌이었다.
실제 액체 표면은 미세물결이 흐르고 잘게 명멸하며 반짝임을 부순다(scintillation).

## 변경 (`normalNode`, GPU 프래그먼트)
시간 uniform(`rippleTimeU` ← 렌더 루프의 `simT`)을 노이즈 좌표에 넣었다:
- **xy에 시각을 더해** 물결이 스월 방향으로 흐른다(이동): `x·freq + 0.6·t`, `z·freq − 0.5·t`
- **3번째 옥타브 좌표에 시각**을 넣어 fbm 모양이 바뀌며 반짝임이 명멸: `1.5·t`

스월 활성도(`rippleActU`) 게이팅은 그대로 — 정지 시 섭동 0(유리처럼 매끈).

## 성능
GPU 픽셀 셰이더에 덧셈 몇 개. fbm 옥타브 수(3)·정점 수 불변. 사실상 무비용.
부수 효과로 미사용이던 `simT`를 쓰게 돼 lint 경고 하나 해소.

## 검증
- `/lab` SSR 200, 컴파일·타입 통과.
- TSL 셰이더 **런타임**(실제 반짝임 명멸)은 headless로 못 봐, 배포본 육안 확인 필요.

## 튜닝 메모 (배포본에서 조정)
이동 0.6/0.5·명멸 1.5는 headless라 눈으로 못 맞춘 보수적 값이다. 너무 빠르면
어지럽고 느리면 정지처럼 보이니, 배포본을 보고 이 계수를 조정한다.
