# 스월 액체감 개선 ④ — 과녁(동심원) 완화: 스월 중 동적 거칠기

## 문제 (사용자 관찰)
빙글빙글 돌 때 표면에 **과녁 같은 동심원**이 보여 어색하다.

## 원인
표면에서 순수 동심원을 만들 수 있는 건 방위(θ) 파동이 아니라 **반경 함수**뿐이다.
범인은 스월 세기에 비례하는 **회전 오목 포물면** `K·r²`(K = swirlMag·1.1, line 1254·1526).
원심력으로 중심이 파이는 건 물리적으로 맞지만, 그 면이 **매끈한 오목거울**(roughness
0.14)이라 환경 반사를 동심원으로 집속한다 → 과녁. 실제 와인은 표면이 흐트러져
이런 깨끗한 거울 링이 안 생긴다.

## 변경 (`bodyMat.roughnessNode`)
스월 활성도에 비례해 표면 거칠기를 올린다:

```
roughness = 0.14 + waveAct·0.25   (정지 0.14 ~ 스월 최대 0.39)
```

움직이는 수면은 실제로 미세물결로 난반사하므로 물리적으로도 맞다. 오목면이
거울 링을 못 맺어 과녁이 흐트러진다. **정지 시엔 0.14(유리 같은 매끈함) 그대로** —
가만히 둔 와인의 또렷한 하이라이트는 보존된다.

## 성능
렌더 루프에서 uniform 대입 1회. 정점·법선·셰이더 비용 불변.

## 검증 / 튜닝
- `/lab` SSR 200, 컴파일·타입 통과.
- 계수 0.25(최대 거칠기 0.39)는 headless라 눈으로 못 맞춘 값. 배포본에서:
  - 과녁이 여전히 보이면 계수를 더 올린다(예: 0.35).
  - 스월 중 와인이 무광 젤리처럼 탁해지면 낮춘다.
