# 스월 액체감 개선 ② — trochoidal(뾰족한 마루) 파형

## 문제
표면 파동이 저차 사인파(`cos(θ−φ)` 등)뿐이라 마루가 둥글다. 둥근 마루는 그 자체로
탱탱한 젤리 표면처럼 읽힌다. 실제 중력파는 **마루가 뾰족하고 골이 완만**하다(비대칭).

## 변경 (`surfWaveH`)
주 크레스트(mode-1)에 Stokes 2차 항을 더해 파형을 뾰족하게:

```
m1s = m1 + WCREST_SHARP·(m1² − 0.5)   (WCREST_SHARP = 0.3)
```

`(m²−0.5)`는 위상 평균이 0이라 **부피가 보존**된다(수면이 전체로 떠오르지 않음).
mode-2,3 로브는 작아 그대로 둔다.

## 수치 검증 (`troch.js`)
| eps | 마루 | 골 | 마루/골 비 | 평균(부피) | 극값 |
|---|---|---|---|---|---|
| 0 (사인) | 1.000 | −1.000 | 1.00 | 0 | 정상 |
| **0.3 (채택)** | **1.14** | **−0.86** | **1.33** | **0** | 정상 |
| 0.5 | 1.25 | −0.75 | 1.67 | 0 | 경계 |

`dh/dφ = −sinφ(1+2ε·cosφ)`의 여분 근 조건 `cosφ = −1/2ε`는 ε<0.5에서 |·|>1이라
**이중 peak가 생기지 않는다**(마루 하나·골 하나 유지). 0.3은 여유 있게 안전.

## 성능
`surfWaveH`당 곱셈 1 + 덧셈 2. 컬럼당 15회 × 97컬럼 = 프레임당 ~1,455회 추가.
정점 수·법선 비용 불변.

## 최종 시각 확인 (사람 필요)
벽을 타고 오르는 크레스트의 마루가 뾰족해졌는지, 젤리 같은 둥근 표면감이 줄었는지
배포본에서 육안 확인.
