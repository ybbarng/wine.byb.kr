# 스월 액체감 개선 ⑦ — 볼록 착시 완화(반사 단서 회복)

## 문제 (사용자 관찰)
오목해야 하는데 볼록처럼 보인다.

## 진단
형상은 수학적으로 오목이 확실하다(`평면 + K·r²`, K>0 → 벽>중심). 따라서 볼록은
광학 착시. 유력 원인은 ⑥에서 roughness 를 0.49까지 올려 표면이 무광이 되며
**오목을 알려주던 반사 왜곡이 사라진 것** — 그러면 Beer-Lambert 두께 밝기(중심이
얕아 밝음)만 남고, 눈은 "중심이 밝다 = 솟았다(볼록)"로 해석한다.

## 변경 (실험적, 가설 A)
```
roughness = 0.14 + waveAct·0.18   (스월 최대 0.49 → 0.32)
```
반사 단서를 되살려 오목이 읽히게 한다. 과녁(회전선)이 조금 돌아올 수 있으나
볼록 오인이 더 큰 문제라 판단.

## 다음 (가설 B, 이걸로 안 되면)
조명 방향 착시(crater illusion) — 환경광 밝은 부분이 아래에 있으면 오목/볼록이
뒤집힌다. 그 경우 환경맵 방향/조명을 손봐야 한다(roughness 무관).

## 검증
컴파일 통과. 볼록↔오목 인지는 배포본 육안 확인이 유일한 판단 수단.
