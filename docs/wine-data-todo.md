# 와인 데이터 — 나중에 보강할 일

시음 기록을 넣을 때는 "연결에 필요한 최소한"(이름·종류·좌표·확실한 품종)만
채우고, 조사해야 하는 서술형 정보는 여기 모아 **마지막에 일괄로** 보강한다.
입력 스크립트: `scripts/add-tastings.ts` (slug upsert라 재실행해도 중복 없음).

## 일괄 보강 (조사 기반)

- **산지(Region)**: `descriptionKo`·`climate`·`soil`·(가능하면) `boundaryGeojson`
  경계 폴리곤. 새로 만든 산지는 좌표 핀만 있음 → 지도가 상위 국가 뷰로 보임.
  - 새로 만든 산지: 상세르, 보르도(일반), 오스트리아, 부르겐란트, 샤블리,
    스페인, 리베라 델 두에로
- **와이너리(Producer)**: `descriptionKo`(소개)·`founded`(설립)·`philosophy`.
  지금은 **이름만** 채워져 있음. 보여줄 곳(생산자 페이지 or 와인 상세의 생산자
  섹션)도 함께 만들어야 화면에 노출됨.
- **와인(Wine)**: 정확한 `abv`·`notesKo`(시음 포인트)·`foodPairing`·블렌드 비율.

## 개별 항목 특이사항

- **고세 그랑 로제 브륏 NV** — 로제 샴페인인데 `type=champagne`로만 넣어 잔 색이
  분홍이 아니라 연한 샴페인색. 로제 샴페인 핑크 틴트 처리 방법 마련 필요.
- **에스터하지 클림트 레드** — 품종 비어 있음(블렌드 불확실, 츠바이겔트/
  블라우프랭키쉬 계열 추정). 확인해서 채우기.
- **까를로 사니 수수마니엘로** — 기존 "풀리아" 산지 항목명이
  `타란티노, 만데리아, 뿔리아`라 그대로 붙음. 풀리아 산지명/구조 정리.
- **또스띠 모스카토 다스티** — `sparkling`으로 넣음. dessert/frizzante로 재분류
  검토(살짝 스파클링 + 단맛).
- **상세르 등 임시 abv** — 상세르 13% 등 추정값 검증.
- **겹친 마신 날** — 상세르 + 에스터하지 둘 다 2025-09-12(같은 주 금요일).
  그대로 둘지 하루씩 벌릴지 결정. (규칙: 같은 주면 그 주 금요일로 추정)

## 프로세스

- **서버 DB 반영** — 로컬 입력을 다 마친 뒤 서버 `data/wine.db`에 반영.
- **마신 기록 기준 기능 보강** — 입력 끝난 뒤, 실제 마신 와인들을 바탕으로
  다른 기능을 풍부하게.
